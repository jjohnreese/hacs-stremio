# Visual guide

The updated live gallery is pending installation of version 0.6.0. Screenshots of an older installation are not evidence of this version's behavior. The release ships first so its cards can be installed and captured in Home Assistant.

The gallery will cover desktop and phone catalog browsing, genre/search/IMDb sorting, library filtering, Continue Watching, recommendations and Find Similar, first-click series details, season/episode selection, Title Info, stream inspection, and retained playback/media-browser controls.

Only Stremio card/dialog content belongs in the captures; Home Assistant's sidebar and top bar are excluded. Public catalog/title metadata can be captured directly. Personal library contents, watch history/progress/counts, entity/account/device names, network addresses, and add-on URLs require removal or explicitly labeled demonstration data. Every saved image must be inspected before it is published.

The existing PNG files in this directory were inherited from upstream and depict its earlier interface and data. They are retained as historical assets, not presented as current fork screenshots.
